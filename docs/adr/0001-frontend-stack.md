# ADR 0001 — Front-end stack: React + Vite + TypeScript (PWA)

**Date:** 2026-10-12
**Status:** Accepted

## Context
The game must be a client-only web app, static-hostable on GitHub Pages,
installable as a PWA on Android, and offline-capable. It will grow to many
game modes and screens.

## Decision
Use React + Vite + TypeScript, shipped as a PWA (web app manifest +
service worker generated by Vite).

## Alternatives considered
- **Vanilla TS + Vite:** smallest bundle, but the planned growth (multiple
  game modes, several screens, adaptive-progress UI) would force us to
  reinvent component/state management.
- **No framework decision yet:** rejected to let design proceed.

## Consequences
- Slightly larger bundle than vanilla; acceptable because SVG map data is
  the dominant weight and is lazy-loaded per map.
- Component model supports additive growth of modes/screens.
- Static output; no back-end.
